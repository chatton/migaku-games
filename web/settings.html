Game profiles

The active profile names the game for overlay captures (the gallery filters by it) and holds the per-game options. Switch profiles when you switch games.

About freezing

With freezing on, the overlay hotkey pauses the game's processes (SIGSTOP) while the overlay is up and resumes them (SIGCONT) when you hide it, so nothing moves on while you read. Linux only. With no process name set, the running Steam game is frozen; for anything else (emulators, GOG, Lutris), set part of its executable's name, e.g. duckstation or retroarch.

Don't use it for online games: they'll time out. You might hear a short click when the audio stops. If a game ever stays frozen, run python3 migaku_games.py --resume.
