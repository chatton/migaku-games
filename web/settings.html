Game profiles

ProfileFreezeProcess

The active profile tags overlay captures with its name and holds the per-game options. Freezing (experimental, Linux) pauses the game's processes while the overlay is up; with no process set it freezes the running Steam game. If a game is ever left frozen: python3 migaku_games.py --resume.

Viewer keybindings

The overlay hotkey itself is a desktop shortcut (KDE: System Settings → Shortcuts), not set here.
